# MediCare Website - Client Side Development Coursework 2

## Project Overview

NHS Medicare is a multi-page healthcare website designed to help patients easily access medical services, view transparent pricing, and book appointments online. The website is built using semantic HTML5, CSS3 (Flexbox/Grid), JavaScript, and jQuery, with client-side data storage using localStorage.

## Project Purpose

The main purpose of this project is to provide a user-friendly digital platform that bridges the gap between patients and healthcare providers. It simplifies the process of finding medical services and booking appointments, reducing the need for phone calls and administrative delays.

## Pages

1. **Home Page (index.html)** - Welcome page with hero section, features, and call-to-action buttons
2. **Services Page (services.html)** - Displays 6 medical services with descriptions and pricing
3. **Booking Page (booking.html)** - Appointment booking form with validation and localStorage
4. **Contact Page (contact.html)** - Contact details and enquiry form

## Technologies Used

- HTML5 (Semantic elements)
- CSS3 (Flexbox, Grid, Transitions, Animations)
- JavaScript (Form validation, DOM manipulation)
- jQuery (Click events, animations)
- localStorage (Client-side data storage)

## Features

- Responsive design (mobile-friendly)
- Interactive service cards with jQuery click events
- Form validation on booking page
- LocalStorage for saving booking data
- Active navigation state highlighting
- Hero background image on services page
